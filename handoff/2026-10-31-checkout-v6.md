# Release workflow: actions/checkout v6

PR #4 · Claude · 2026-10-31

## What changed
- `.github/workflows/release.yml` uses `actions/checkout@v6` instead of `@v4`, as fingerprint-fix-sdcp's workflow does.

## Why
- The v0.3.0 release run warned that `actions/checkout@v4` targets Node.js 20, which GitHub has deprecated.
- The same run noted that `ubuntu-latest` is moving to Ubuntu 26. That's fine for this workflow (it only uses bash, awk, sed and `gh`), so nothing changed for it.

## Tested
- The YAML parses. The next release runs it.
