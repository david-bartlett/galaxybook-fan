# Executable bits

PR #11 · Claude · 2026-10-31

## What changed
- `lib/galaxybook-fan` and `tools/build-check-script.sh` are now executable in git (they went in as 644 in #10 and #8). `lib/fanpaths.sh`, `lib/fan-dkms.sh` and `lib/models.sh` stay 644: they're only sourced.

## For the next person
- New scripts that are run directly need `git update-index --chmod=+x <file>` (or `chmod +x` before `git add`). Check with `git ls-files -s | grep 100644` for any `.sh` that should run. `install.sh` installs the command with `install -m 755`, so installs weren't affected.
